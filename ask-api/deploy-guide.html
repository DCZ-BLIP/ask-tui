前置准备

  1. 智谱 API Key — 访问 智谱开放平台 获取 GLM-4-Flash 的 API Key（免费）
  2. GitHub 账号 — 用于托管代码仓库
  3. Render 账号 或 Fly.io 账号 — 二选一即可

代码已初始化为 Git 仓库，需要推送到 GitHub。

方案对比

方案 A: Render

推荐

  • 免费 750 小时/月
  • 512MB 内存
  • PostgreSQL 数据库（1GB）
  • 15 分钟无流量自动休眠
  • 冷启动约 1 分钟
  • 缺点：数据库 90 天后过期需重建
  • 缺点：无持久化磁盘

方案 B: Fly.io

持久化更好

  • 免费 3 个 VM (256MB)
  • 3GB 持久化卷
  • SQLite 直接持久化
  • 空闲自动停机/启动
  • 东京区域（离中国近）
  • 优点：数据不丢失
  • 缺点：需安装 flyctl CLI

方案 A：部署到 Render

架构说明：Render 免费套餐不支持持久化磁盘，因此使用 Render PostgreSQL 数据库。后端 database.py 已自动适配：检测到 postgresql:// URL 会自动转为 postgresql+asyncpg://，无需手动修改代码。
1推送到 GitHub 
# 在 GitHub 创建新仓库 ask-tui
# 然后在本地推送：

cd /workspace
git remote add origin https://github.com/你的用户名/ask-tui.git
git branch -M main
git push -u origin main
2在 Render 创建 Blueprint
  1. 登录 Render Dashboard
  2. 点击 New + → Blueprint
  3. 选择刚推送的 GitHub 仓库 ask-tui
  4. Render 会自动识别 render.yaml，显示将创建的服务：
    • 1 个 PostgreSQL 数据库 ask-api-db
    • 1 个 Web Service ask-api（Python, Free 套餐）
  5. 点击 Apply 开始创建
3配置密钥

在 Render Dashboard 的 ask-api 服务 → Environment 中设置：

  • LLM_API_KEY → 粘贴你的智谱 API Key
  • ADMIN_API_KEY → 已自动生成（或手动设置一个随机字符串）
  • DATABASE_URL → 已自动从 Postgres 数据库引用

查看自动生成的 ADMIN_API_KEY：在 Environment 页面找到 ADMIN_API_KEY，点击显示值并复制保存。

4等待部署完成

Render 会自动执行：

  1. 创建 PostgreSQL 数据库
  2. 构建 Python 环境 (pip install -r requirements.txt)
  3. 启动服务 (uvicorn app.main:app --host 0.0.0.0 --port $PORT)
  4. 应用启动时自动创建所有数据库表

部署成功后获得 URL：https://ask-api-xxxx.onrender.com

5验证部署 
# 健康检查
curl https://ask-api-xxxx.onrender.com/api/health

# 应返回:
# {"status":"ok","service":"ask-api","version":"0.3.0","database":"ok"}

# 生成邀请码（用你的 ADMIN_API_KEY 替换）
curl -X POST "https://ask-api-xxxx.onrender.com/api/auth/admin/invite-codes?count=10" \
  -H "X-Admin-Key: 你的ADMIN_API_KEY"

# 应返回 10 个邀请码
注意：Render 免费套餐 15 分钟无请求会自动休眠。首次请求（冷启动）需要约 30-60 秒。可设置外部定时 ping（如 UptimeRobot 每 10 分钟 ping /api/health）保持唤醒，但会消耗免费额度。

方案 B：部署到 Fly.io

优势：Fly.io 免费套餐支持 3GB 持久化卷，SQLite 数据库可直接持久化，不会因重启丢失数据。无需 PostgreSQL。
1安装 flyctl CLI 
# macOS
brew install flyctl

# Linux
curl -L https://fly.io/install.sh | sh

# 验证
flyctl version
2登录并创建应用 
flyctl auth login

# 进入 ask-api 目录
cd /workspace/ask-api

# 创建应用（fly.toml 已存在，只需 launch）
flyctl launch --no-deploy

# 选择:
#   - Region: Tokyo (NRT)
#   - 不创建 PostgreSQL（使用 SQLite + 持久卷）
#   - 确认 fly.toml 配置
3创建持久化卷并设置密钥 
# 创建 1GB 持久卷
flyctl volumes create ask_data --size 1

# 设置密钥
flyctl secrets set ADMIN_API_KEY=你的随机管理密钥
flyctl secrets set LLM_API_KEY=你的智谱API密钥

# 验证密钥（不显示值）
flyctl secrets list
4部署 
flyctl deploy

# 部署完成后获取 URL:
# https://ask-api.fly.dev
5验证部署 
# 健康检查
curl https://ask-api.fly.dev/api/health

# 生成邀请码
curl -X POST "https://ask-api.fly.dev/api/auth/admin/invite-codes?count=10" \
  -H "X-Admin-Key: 你的ADMIN_API_KEY"

部署后配置

更新 TUI 客户端配置

部署成功后，修改 TUI 客户端默认 API 地址，让朋友开箱即用：

# 编辑 ask-tui/config.py
# 将 DEFAULT_CONFIG 中的 api_base_url 改为你的线上地址:

DEFAULT_CONFIG = {
    "api_base_url": "https://ask-api-xxxx.onrender.com",  # ← 改这里
    "device_id": "",
    "username": "",
}

重新打包 TUI

cd /workspace/ask-tui
./build.sh

# 输出: dist/ask-tui (单文件可执行程序，20MB)
# 分发给朋友即可

TUI 打包分发流程

1修改默认 API 地址

在 ask-tui/config.py 的 DEFAULT_CONFIG 中设置线上 URL

2打包 
cd ask-tui
chmod +x build.sh
./build.sh

# 输出:
# ✓ 打包成功!
#   输出文件: dist/ask-tui
#   文件大小: 20M
3分发
  • 将 dist/ask-tui 发送给朋友（微信/U盘/邮件均可）
  • 同时发送一个邀请码给朋友
  • 朋友执行 ./ask-tui → 弹出激活界面 → 输入邀请码 → 开始使用
跨平台打包：PyInstaller 打包的程序只能在打包时的操作系统上运行。要分发给 Windows/Mac 用户，需要在对应系统上分别打包：
  • Windows: pyinstaller ask-tui.spec 生成 .exe
  • macOS: pyinstaller ask-tui.spec 生成 macOS 可执行文件
  • Linux: 已打包完成 dist/ask-tui

常见问题

Q: Render 部署后访问报 502 / 超时？

A: 免费套餐冷启动需要 30-60 秒，等待 1 分钟后重试。查看 Render Dashboard 的 Logs 页面确认服务已启动。

Q: Render 数据库 90 天后过期怎么办？

A: Render 免费 PostgreSQL 有 90 天有效期。到期前 Render 会发邮件提醒。可以创建新的 PostgreSQL 实例，修改 DATABASE_URL 环境变量指向新数据库，应用重启后会自动建表。或者迁移到 Fly.io 方案（数据不丢失）。

Q: AI 对话返回 500 错误？

A: 检查 LLM_API_KEY 环境变量是否正确设置。查看 Logs 中的错误信息。智谱 API Key 需要在智谱开放平台获取。

Q: 限流 429 错误？

A: 默认每设备每天 200 次请求。可在 Render/Fly 环境变量中调整 DAILY_REQUEST_LIMIT。

Q: TUI 启动后显示"无法连接服务器"？

A: 检查 ~/.ask-tui/config.json 中的 api_base_url 是否正确。如果是 Render 免费套餐，可能是服务在休眠，等待 1 分钟后重试。

Q: 如何更新已部署的服务？

A: 将新代码推送到 GitHub main 分支，Render 会自动重新部署。Fly.io 使用 flyctl deploy 更新。
